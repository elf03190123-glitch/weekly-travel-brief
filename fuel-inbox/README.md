# 유류할증료 자료 올리는 곳

매달 받은 유류할증료 자료를 이 폴더에 올리면 몇 분 안에 브리프의 `유류할증료` 탭이 갱신됩니다.

- **올리기**: https://github.com/elf03190123-glitch/weekly-travel-brief/upload/main/fuel-inbox
  → 파일을 끌어다 놓고 아래 **Commit changes**를 누릅니다.
- **형식**: 캡처 이미지(png·jpg), PDF, 엑셀(xlsx), 워드(docx), csv·txt
- **자료 종류**: 대한항공 유류할증료 구간표, ROE(적용 환율), 아시아나 유류할증료표, 트리니티항공 부과군표. 한 번에 여러 개를 올려도 됩니다.
- **결과 확인**: Actions → `fuel` 실행 기록. 처리한 원본과 보고서(`report-….md`)는 `fuel-sources/<YYYY-MM>/`로 옮겨집니다.
  반영하지 못한 자료는 `fuel-sources/not-applied-…/`에 이유와 함께 남습니다.

주의: 이 저장소는 공개입니다. 올린 파일도 공개됩니다. 항공사 공지처럼 공개된 자료만 올립니다.
